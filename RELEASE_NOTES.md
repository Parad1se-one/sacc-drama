# Release Notes

## v1.0.0
Date: 2026-06-01

Initial public code release of `SACC + DRAMA`.

Included:

- the DRAMA benchmark package with `easy` and `hard` splits
- baseline MARL implementations and generic training entrypoints
- the standalone SACC implementation
- evaluation and monitoring utilities

Excluded:

- paper assets
- checkpoints
- TensorBoard event files
- historical experiment logs and result archives

Notes:

- this release is intended as a clean reproducibility-oriented code package
- heavy local artifacts were intentionally removed before packaging
